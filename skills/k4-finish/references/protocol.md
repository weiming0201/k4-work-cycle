# Finish document protocol

Finish materializes one closing Account plus a closure stage report for one
exact halted attempt. It binds the pre-Goal Account, Goal, Plan, Run journal,
and halted projection.

The Account core is the same as Observe: subject, boundary, cutoff, sources,
delta, current retained/changed/added items, retired predecessors, generated
identities, and exact Account-predecessor binding. Subject and boundary remain
unchanged; the attempt and its verified outcome supply delta evidence.

Closure is the stage report. It adds exact attempt bindings, one bounded
judgment for every Goal acceptance point and terminal control, terminal state,
result disposition, incomplete package, resume information, and exact journal
reference. The bound Plan and Run retain operation coverage, deviations,
effects, deferred issues, and traces without duplicating the journal into the
Account. Completion requires all Plan operations, acceptance points, and
controls to pass. Non-completion preserves a nonempty incomplete package and
resume position.

The complete trace is evidence for a separately authorized external audit.
Finish performs internal reconciliation and terminal judgment; it does not
become an independent auditor by possessing that evidence.

Finish exposes no future Goal candidate and performs no repair, adoption, or
publication. The generated Finish Account is a legal predecessor for Observe.
Run public `--help` for exact fields and binding syntax.
